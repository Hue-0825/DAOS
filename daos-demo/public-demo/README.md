# DAOS 통합 시연 및 로봇 관제실

[통합 사이트](https://daos-logistics.ryker6365.chatgpt.site/)와 [로봇 관제실](https://daos-logistics.ryker6365.chatgpt.site/robot/)을 제공합니다. 로봇 관제실은 통합 로그인으로 열리며, 별도의 가상 출고 배치와 시연 서버 상태를 탭 안에서 관리합니다.

`node build.mjs`는 Worker와 화면을 빌드합니다. 배포할 때 중앙 서버와 로봇 웹에 동일한 비밀 환경 변수 `DAOS_ROBOT_KEY`를 등록합니다. 로봇 웹의 서버 간 통신에는 선택적으로 `DAOS_CENTRAL_ACCESS`를 사용합니다. 실제 비밀값은 Sites 환경에서 관리합니다.

## 통합 로그인

통합 사이트에서 ChatGPT에 로그인한 뒤 운영 화면을 열면 각 웹에 시연 세션이 연결됩니다. ChatGPT에 로그인한 사용자는 시연 비밀번호를 한 번 입력해 권한을 확인합니다. 사이트별로 직접 받은 기존 공유 링크도 사용할 수 있습니다. 각 운영 웹의 시연 세션이 만료되면 통합 사이트에서 그 화면을 다시 엽니다.

메인 관제센터·스토어·허브·기사 웹은 각자의 `DAOS_SSO_KEY`를 사용합니다. 통합 사이트에는 역할별로 대응하는 `DAOS_SSO_CENTRAL`, `DAOS_SSO_SHOP`, `DAOS_SSO_HUB`, `DAOS_SSO_DRIVER`를 설정합니다. 통합 사이트의 `DAOS_DEMO_PASSWORD`는 Sites 환경에 비밀값으로 설정합니다. 기존 초대 링크와 소유자 확인에는 메인 서버와 통합 사이트에 설정된 `DAOS_ROBOT_KEY`를 사용합니다.

## 로봇 시연

오른쪽 위 **백업 작업표 전송**을 누르고 **시연 서버 연결 끊기**를 누릅니다. DAOS를 켜면 백업 작업표의 상자를 다음 공정으로 인계하며, 끄면 로봇이 안전 정지 상태로 대기합니다. **다시 시작**으로 배치를 초기화합니다.

## 프로젝트 소개와 복구 검증

[프로젝트 소개 및 기술 검증](https://daos-logistics.ryker6365.chatgpt.site/project.html)에서 두 보고서의 원문 검토, 시연 구현과 검증 범위를 확인할 수 있습니다.

배송 서버는 배차 버전과 집하·구간 출발을 확인한 뒤 기존 접수 기록을 대조합니다. 로봇 관제실은 45초짜리 백업 작업표와 중앙 스냅샷·현장 인계 기록·가상 스캔 대조를 시연합니다. [DAOS20261110](https://github.com/Hue-0825/DAOS/tree/DAOS20261110)은 변경 전 복구 기준입니다.
