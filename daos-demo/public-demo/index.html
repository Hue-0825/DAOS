03 / 장애 시연

작업표 준비부터 연결 복구까지

  1. 작업표 준비

    메인 관제센터에서 날짜와 시각을 맞추고, 지역 허브에서 시연할 주문을 배차 확정합니다.

  2. 현장 시작

    기사 앱에 배차한 시·도의 작업표가 들어왔는지 확인합니다. 로봇 시연은 별도 출고 배치로 진행합니다.

  3. 서버 연결 끊기

    기사 시연은 메인 관제센터에서 연결을 끊습니다. 로봇 시연은 관제실에서 시연 서버 연결을 끊습니다. DAOS를 켜면 약 1초 동안 전환한 뒤 자동 저장된 작업표로 다시 움직입니다.

  4. 연결 복구

    각 시연의 연결을 복구한 뒤, 기사 앱의 미동기화 건수와 로봇 관제실의 공정 기록을 확인합니다.
