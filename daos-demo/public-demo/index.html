03 / 장애 시연

작업표 준비부터 연결 복구까지

  1. 작업표 준비

    메인 관제센터에서 날짜와 시각을 맞추고, 지역 허브에서 시연할 주문을 배차 확정합니다.

  2. 현장 시작

    로봇 관제실과 기사 앱에서 같은 시·도를 선택하고, 작업표가 들어왔는지 확인합니다.

  3. 서버 연결 끊기

    메인 관제센터에서 연결을 끊습니다. 로봇 관제실에서 저장된 작업과 허브 배차 대기 건수를 확인합니다.

  4. 연결 복구

    메인 관제센터에서 복구한 뒤, 기사 앱의 미동기화 건수와 로봇 관제실의 로컬 공정 기록을 확인합니다.
